# Code Review Checklist

## Reviewer Checklist

- [ ] No secrets or credentials in the diff
- [ ] Changes match the description in the pull request title and body
- [ ] Tests cover the new behaviour and all of them pass
- [ ] Naming and comments are clear enough for a newcomer

## Author Checklist

- [ ] Pull request is kept small and focused on a single concern
- [ ] Self-review of the diff completed before requesting reviewers
- [ ] Screenshots or logs attached for any UI or behavioural change
- [ ] Documentation updated for anything a new teammate would touch
